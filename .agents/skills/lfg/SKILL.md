# Codex Command Skill

This skill is the Codex equivalent of `/lfg` from Every's compound-engineering plugin.
Invoke it with `$lfg`.
Argument hint: `[feature description]`

Run these skills in order. Do not do anything else.

1. `Initialize autonomous loop mode.`
2. `$workflows-plan $ARGUMENTS`
3. `$deepen-plan`
4. `$workflows-work`
5. `$workflows-review`
6. `$resolve-todo-parallel`
7. `$test-browser`
8. `$feature-video`
9. Output `<promise>DONE</promise>` when video is in PR

Start with step 1 now.
