# Bug Investigation

## Workflow

1. Reproduce reported behavior with explicit steps.
2. Capture expected vs actual behavior.
3. Isolate scope, affected surfaces, and likely causes.
4. Provide fix options with confidence levels.
5. Recommend verification coverage for regression prevention.
