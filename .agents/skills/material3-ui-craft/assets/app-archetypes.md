# App Archetypes (M3 presets)

Use these presets to stay coherent across product types while still feeling brand-custom and premium.

## 1) SaaS dashboards + forms (`saas-dense`)

Goal: data-dense, calm, trustworthy.

Token posture:

- Surfaces: emphasize `surface` + `surfaceContainerLow/Container` for grouping.
- Elevation: minimal; prefer outlines/hairlines to separate cards/tables.
- Typography: rely on `titleSmall/titleMedium`, `bodySmall/bodyMedium`, `label*` for forms.
- Spacing: compact scale; use clear section breaks to avoid “wall of fields”.

Avoid:

- Heavy shadows on every card
- Too many accent colors (use semantic statuses sparingly)

## 2) Habit tracker / journaling (`habit-warm`)

Goal: content-forward, warm, reassuring.

Token posture:

- Surfaces: warmer neutrals; use more `surfaceContainer*` to create gentle depth.
- Typography: comfortable body; more generous line height for long-form content.
- Shape: slightly larger corners for a softer feel.
- Motion: subtle but present (small transitions to reinforce completion/progress).

Avoid:

- Overly dense grids; prefer vertical rhythm and clear sections

## 3) Lightweight game UI shell (`game-shell`)

Goal: menus/modals/progress/shop/paywall that feel playful and premium without becoming “enterprise”.

Token posture:

- Color: use `tertiary` as a personality accent; keep primary for core actions.
- Shape: larger corners + more pill shapes where intentional (chips, badges, buttons).
- Elevation: overlays and menus can use higher surface containers; keep base UI relatively flat.
- Motion: snappier feedback; transitions can be more expressive but must respect reduced motion.

Avoid:

- Corporate “form UI everywhere” (overuse of outlined fields, dense tables, heavy dividers)
- Excessive animation that delays interaction
