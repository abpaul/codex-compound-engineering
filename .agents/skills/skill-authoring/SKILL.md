# Skill Authoring

## Workflow

1. Define purpose, trigger, and constraints.
2. Write action-oriented SKILL instructions.
3. Add templates/assets when repetition exists.
4. Validate references and resolve broken guidance.
5. Keep skill scope narrow and composable.
