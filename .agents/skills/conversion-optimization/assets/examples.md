# Conversion Optimization — Examples

Use these as test prompts to confirm the skill triggers correctly and produces the required output contract.

## Layout lane

1. “We have a SaaS pricing page with a free trial CTA. Optimize trial starts and paid conversion. Provide 3 layout hypotheses (Tier 1 or Tier 2 evidence only), a concrete layout implementation plan, and an A/B test spec with guardrails.”
2. “Audit our e-commerce PDP for add-to-cart improvements on mobile. Keep changes minimal (no new features). Prioritize 5 changes and include citations + confidence.”
3. “Our signup flow has a multi-column form on desktop and mobile. Propose a single-column redesign and define success metrics + stop rules.”

## Copy lane

1. “Write 5 in-app paywall CTA variants for a subscription app. Avoid dark patterns. Provide a variant table with evidence tier and an experiment plan.”
2. “Rewrite the hero section copy for a B2B landing page: clarity-first, motivation-first, and a control-safe variant. Include mechanisms/levers used and citations.”
3. “Draft 3 checkout microcopy variants for shipping/returns reassurance, and define guardrails to catch any backfire (refunds, support contacts).”

## Both lanes

1. “Improve donation conversion on a nonprofit landing page. Provide layout hypotheses + 5 copy variants for the primary CTA, plus one unified experiment spec.”
2. “Our onboarding completion is down on Android. Provide cross-platform hypotheses, then propose the smallest set of layout and copy tests to isolate the cause.”
