# Copywriting Conversion Evidence Matrix

Behavior-first evidence base for `$conversion-optimization`.

## Tier Definitions

- `Tier 1`: observed behavioral outcomes in randomized/field contexts.
- `Tier 2`: strong behavior-adjacent evidence with partial external validity.
- `Tier 3`: intention/attitude outcomes without direct conversion behavior.

## Practical Rules Derived from the Matrix

1. Start with `Tier 1` levers for live conversion changes; use `Tier 2/Tier 3` as hypothesis generators only.
2. Treat all framing effects as conditional, not universal; require context-fit checks before deployment.
3. Never use social-proof or scarcity claims without verifiable truth conditions.
4. Pair high-threat copy with high-efficacy action instructions.
5. Add reversal monitoring (complaints, bounce, unsubscribes) whenever using high-pressure persuasion.
