# Ruby Rails Authoring

## Coverage

- Rails application code conventions
- Gem API and README authoring quality

## Workflow

1. Prefer clear domain-centric APIs.
2. Keep controllers thin and models/objects expressive.
3. Use conventional Rails patterns unless justified otherwise.
4. Keep docs concise and example-driven.
